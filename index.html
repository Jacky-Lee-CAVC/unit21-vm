System Help

i3 Keybinds

Mod + Enter → Terminal

Mod + D → App Launcher

Mod + Shift + Q → Close Window

Mod + Shift + R → Reload i3

Mod + Shift + E → Split view

Mod + Shift + H → Horizontal orientation

Mod + Shift + V → Vertical orientation

System Commands

sudo dnf upgrade --refresh → Update system

fastfetch → System overview

df -h → Disk usage

du -sh ~/* → Check what is using disk space

clamscan → Scan the system for malware

Navigation

Power Menu (top left) → Shows system functions

Apps → Mod + D
